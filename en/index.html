In plain words

Not a developer? Here is what this is

AI is no longer a single chat window. People use several AI tools at once and set up helpers with separate jobs inside them: one writes, one researches, one checks. These helpers are called agents.

As the number of agents grows, it gets hard to tell which one is working, which one is idle and how much each one uses. OZMIRA is a control panel that shows all of them on one screen, like a workshop job board or a car dashboard.

It is not tied to one AI or one kind of work. Agents that write, code, research or answer customers are tracked on the same screen, whatever tool they were built with and whatever they are for. The same window also has a shared chat: you write in one box and the message goes to the right AI for its topic. The free version shows 2 systems and 7 agents; Pro has no paid limit.

What it is not: OZMIRA is not an AI, it does not run your agents for you and it does not sell AI services. The answers in the chat also come from the tools you installed yourself. OZMIRA makes what you already have visible, measurable and reachable from one place.

Features

What it does

One scene

Each system appears in its own color and shape. All in the same scene, connected to the animated OZMIRA mark at the center.

Live signal

When an agent starts and finishes you send a one-line command; the signal goes from the center to the agent and returns when the job is done.

Token counter

The token count you give at the finish notice is added up in the scene. You see at a glance how much each system spent.

Shared chat

Write in one box; OZMIRA sends the message to the right AI for its topic and keeps your conversations in separate projects. The command-line tool of that AI must be installed on your computer.

Control panel

Summary tiles, bars for the last 7 days, a searchable agent table, an event list and CSV export.

Flow and cost

The Flow tab in the panel shows input and output tokens per system and per agent. You enter the prices and OZMIRA works out an estimated cost. It is an estimate; your real bill may differ.

Your own agents

Point to an agent folder and the file names become the agent list; or type the names by hand.

Step-by-step guide

Ten short lessons: first the idea and setup, then automatic events, designing a good agent and backups.

App window

Opens in its own window instead of a browser tab; you can put a shortcut on the desktop. Needs Chrome, Edge or Brave.

OZMIRA chat

Write in one box and the right AI answers

OZMIRA looks at the words in your message, works out the topic and sends the message to the system assigned to that topic, among the ones you have set up. It does this by calling that AI's command-line tool installed on your computer, so it simply runs the tool you already use.

If the topic is unclear, the message goes to the first system whose tool is installed. Above each answer you see which AI was chosen and why; you can also pick the target yourself.

Projects

Each project keeps its own conversation, so the messages of one job do not mix with another. The free version lets you open 2 projects.

Notes to Obsidian

If you want, chat notes are saved into your own Obsidian vault. It is optional; the chat works the same without it.

Tools you need

A command-line tool is the small text-based program an AI installs on your computer: claude for Claude, codex for ChatGPT, gemini for Gemini. If the tool is not installed, the message is saved and you send it again once it is. No tool is connected for Grok yet.

Three steps

How it works

  1. Add your system

    In the wizard on first start, name the center and add your systems. There are ready templates (Claude, ChatGPT, Gemini, Grok, Other); you can change name, style and color.

  2. Connect

    The Connect button in the dock lets you copy ready-made commands for your systems. You can call them from your own scripts or from the before and after steps of your tools.

    python3 ozmira.py olay claude yazar basla
python3 ozmira.py olay claude yazar bitti 1200

    The command words (olay, basla, bitti) are the same in every language.

  3. Watch the scene

    The working agent glows, the signal goes and returns, the token counter rises. The only things sent are system, agent name, event type and token count; no prompts, replies or code.

Privacy

What goes where, stated plainly

  • No account, no cloud. Your system definitions, events, chat history and access key are kept on your computer only.
  • Closed to the network. The server listens on this computer only; other computers cannot connect. Every request needs a randomly generated key.
  • Your chat messages: are handed only to the AI tool that is installed on your computer and that you already use; that tool talks to its own service as it always does. OZMIRA sends the messages nowhere else. The chat is turned off in --lan mode.
  • Sharing is off by default. If you allow it, at most once a day the version, plan, a random installation ID and counters are sent anonymously. Your system names, agent names, task labels, folder paths, token amounts and IP address are not sent.
  • This website: counts visits with GoatCounter, without cookies. Only totals such as page, date, browser type and referrer are kept; no personal data or cookies. The app itself does not do this.
  • The write-to-us form: the text, type, page language and optional email you send reach us as an email and stay in our inbox. Your IP address is not stored; to prevent abuse it is only counted per minute at that moment.
  • OZMIRA's only external connection of its own: the 3D library (three.js) is loaded from jsdelivr. With python3 ozmira.py vendor you can download it once and then run without internet.

Questions

Frequently asked questions

Does OZMIRA send my messages anywhere?

Only to the AI tool you already use on your own computer. OZMIRA itself has no server on the internet; it hands the message to that tool's command-line program, and the tool does the rest with its own service as it always does. The chat history is kept in the data folder on your computer.

Does OZMIRA connect to my AI systems?

Not for the scene and the panel: you tell it with a command when an agent starts and finishes. Only in the shared chat, when you send a message, does it run that AI's command-line tool on your computer.

Is Python required?

Yes. The app uses only the Python standard library; you install no extra packages.

Is this an .exe?

No. On Windows, ozmira-uygulama.bat or a desktop shortcut made with python ozmira.py kisayol opens like an app, but it is a shortcut; there is no single-file installer yet.

Where is my data kept?

In the .ozmira folder in your home directory. If you stop the app and delete this folder, everything is reset.

Can I look from my phone?

There is an optional --lan mode; because anyone on the same network can reach the server, do not use it on shared networks such as cafes, hotels or schools.
